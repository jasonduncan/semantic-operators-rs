## Unreleased

## 0.1.0-alpha.2 — 2026-10-17

- Add CPython summation attribution and Python license notices; correct combined
  package metadata to MIT AND Python-2.0 while retaining original project MIT terms.
- Improve public onboarding, feature labels, contribution/versioning guidance,
  license/source checks, full-history secret scanning and pinned CI actions.
- Retain and latch interrupted flow attempts so cancelling a polled request
  cannot erase its trace or make partial execution appear successful.
- Document public error contracts and add executable offline API examples.
- Enforce focused library hygiene lints and add dependency audits, weekly
  dependency update PRs, and a contributor review checklist.

## 0.1.0-alpha.1 — 2026-10-17

- Implement validated Boolean/Choice/Score/Box questions, typed answers, exact
  normalization, metadata and Python schema-1 wire translation.
- Add object-safe async providers, typed operators, batching, cascade, deadlines,
  traced flows, bounded per-item recipes, ranking and offline evaluation.
- Add optional TypeSafe HTTP/multipart transport, explicit image assets, frames,
  localization and blocking facade.
- Add Python differential fixtures, synthetic examples, transport/runtime edge
  tests, feature/MSRV/platform CI, and actual Cargo archive consumer checks.
- Include optional integrations in docs.rs builds and package the release notes.
- Add a standalone triage reference consumer and bounded synthetic evaluation
  tools in the repository; these applications and datasets are not in the crate.
- First crates.io alpha release. API remains unstable; no live model
  qualification or performance claims.
