# Governance and support

The repository maintainer is [Jason Duncan (@jasonduncan)](https://github.com/jasonduncan).
The maintainer reviews contributions and decides API direction, compatibility
changes and releases. [CODEOWNERS](.github/CODEOWNERS) identifies the reviewer;
it does not by itself enforce branch protection or guarantee review.

Propose changes through [GitHub issues](https://github.com/jasonduncan/semantic-operators-rs/issues)
and pull requests. Use [Discussions](https://github.com/jasonduncan/semantic-operators-rs/discussions)
for usage and design questions. Describe concrete use cases, alternatives and compatibility
impacts so decisions can be reviewed with the code and evidence. Treat other
contributors respectfully and keep discussion focused on the work.

There is no guaranteed response time, release schedule, support SLA or long-term
maintenance commitment. A merged contribution need not trigger a release. The
[versioning policy](VERSIONING.md) describes the current alpha status and future
compatibility rules; [Contributing](CONTRIBUTING.md) explains the development and
review process.

This file does not establish a formal conduct-enforcement process or a new
contributor agreement. Those policies require an explicit maintainer decision
and, for private conduct reports, a real reporting contact. Do not put credentials,
private input data or vulnerability details in ordinary public issues. For
vulnerabilities, follow [Security](SECURITY.md); that channel is not a conduct-reporting contact.
